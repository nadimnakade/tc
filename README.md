# Titan Consultancy — Revamp

Animated landing page revamp for **titan-consultancy.com**.

Built with Vite + React + Framer Motion + Tailwind + Lenis.

## Run locally

```bash
npm install
npm run dev      # http://localhost:5174
npm run build    # → dist/
npm run preview  # serve built output
```

## Deploy

Pushes to `main` trigger the GitHub Actions workflow at `.github/workflows/deploy.yml`, which builds and publishes to **GitHub Pages**.

Live site: <https://nadimnakade.github.io/tc/>

## Tech

- **Vite 5** + React 18
- **Framer Motion** for all animation (scroll, hover, layout)
- **Lenis** for buttery smooth wheel scrolling
- **Tailwind CSS 3** for styling
- **Lucide React** for icons
